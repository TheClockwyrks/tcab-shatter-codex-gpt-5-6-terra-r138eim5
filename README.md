# Shatter

Shatter is a fast, browser-based gravity-well rock shooter. Pilot an inertial
ship around a hungry star, curve shots through its pull, break armored rocks
into fragments, and save the guided torpedo for the moment it matters.

## Run it

```sh
npm ci
npm run dev
```

Build the self-contained static site with `npm run build`; the result is in
`dist/`.

## Controls

Use **ARROWS** or **WASD** to steer and thrust, **SPACE** to fire, and **F** to
launch the homing torpedo. **P** or **ESC** pauses, **ENTER** confirms menus,
and **M** toggles audio.
